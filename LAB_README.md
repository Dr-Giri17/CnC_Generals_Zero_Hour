# Generals / Zero Hour — Experimental Lab

This fork is an **experimental, unofficial, community/modding workspace** based on Electronic Arts' published Command & Conquer: Generals / Zero Hour source code.

## Current goal

The immediate goal is deliberately small:

> Build a free, for-fun Zero Hour mod/prototype and learn the engine + WorldBuilder pipeline without turning this repository into a large production project.

Current track:

- preserve EA upstream and license notices;
- keep `main` close to upstream;
- make experiment changes on dedicated lab branches;
- first prove build + WorldBuilder + one custom map + one custom unit;
- use original EA/C&C assets only where the applicable modding rules permit;
- do not treat this branch as a commercial product.

## Branch policy

- `main` — upstream-compatible EA fork.
- `lab/for-fun-rts-experiment` — our documentation and experimental mod work.
