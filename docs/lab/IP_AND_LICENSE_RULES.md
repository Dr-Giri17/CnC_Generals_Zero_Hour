# IP / License Rules for This Experiment

This is a practical project rule sheet, not legal advice.

## Upstream code

The EA source release in this repository is under **GPLv3 with EA additional terms**.

Therefore:

- keep `LICENSE.md`;
- keep applicable notices;
- mark modified versions as modified;
- do not claim EA endorsement or affiliation;
- do not use EA trademarks as branding for an independent product;
- if distributing GPL-covered binaries, satisfy the corresponding-source obligations.

## For-fun C&C mod track

For the current experiment:

- treat it as a **free C&C/Zero Hour mod**;
- do not monetize the mod;
- follow EA's published modding guidelines;
- do not assume all EA assets are freely reusable outside the mod context;
- do not add C&C music unless the applicable EA rules expressly permit it.

## Independent standalone track

If later we want a separate commercial RTS:

- use a different name and branding;
- replace EA/C&C factions, characters, names and lore;
- replace maps, models, textures, UI art, voices, music and cinematics;
- remove runtime dependency on original C&C data;
- preserve GPL obligations for covered engine code;
- run a dedicated GPL/IP legal review before commercial release.

## Third-party SDKs

Do not commit proprietary SDKs such as Miles, Bink, old 3DS Max SDK components, SafeDisc materials or other non-redistributable dependencies.

## Rule of thumb

```text
C&C identity/assets + Zero Hour mod context
→ FREE MOD

Own IP/assets + compliant GPL engine fork
→ separate legal/commercial review
```
